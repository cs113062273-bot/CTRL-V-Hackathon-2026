What it does

  1. Audits the rendered page with axe-core (WCAG 2.2 A/AA) plus checks axe misses: mouse-only click handlers, vague link text, missing input purpose, asterisk-only required fields.
  2. Repairs the source — labels, alt text, names, contrast colours with the same hue, landmarks, skip links, ARIA mistakes. No overlay script; the fixes live in your HTML.
  3. Re-audits the fixed code and marks every change as verified or not. Guesses are flagged for your review and can be edited or rejected.
